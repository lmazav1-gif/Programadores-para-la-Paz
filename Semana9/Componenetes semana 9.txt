Sistema operativo:
Es el software base que permite ejecutar Node.js y gestionar los recursos del computador.

Node.js:
Es el entorno que permite ejecutar JavaScript en el servidor y crear aplicaciones backend.

Aplicación server.js:
Es el archivo principal donde se define el servidor, sus rutas y su comportamiento.

Puerto:
Es el canal (en este caso 3000) por donde el servidor recibe y envía solicitudes.

Logs:
Son registros del sistema que muestran eventos, errores y actividades del servidor para su monitoreo.
