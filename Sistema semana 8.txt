El comando uname -a muestra información detallada sobre el sistema operativo, como el nombre del sistema, la versión del kernel, la arquitectura y otros datos técnicos.

El comando whoami muestra el nombre del usuario que actualmente está utilizando el sistema.

Conocer esta información es útil para administrar un servidor porque permite identificar el sistema operativo que se está utilizando, verificar configuraciones, solucionar problemas técnicos y comprobar qué usuario está ejecutando determinadas acciones.
